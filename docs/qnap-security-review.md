# QNAP mesh-cos-mcp Security Review

Status: v4.1.1 release candidate. Repository and container controls are independently verified in CI; live QNAP and ChatGPT product-surface acceptance remain operator-executed.

## Threat-boundary conclusions

- Trust model: ChatGPT and all model-controlled or retrieved text are untrusted for authority. Canonical registry, role contracts, TaskLedger state, approval records, and runtime policy remain authoritative.
- Network model: OpenAI Secure MCP Tunnel is outbound-only. The MCP protocol endpoint is restricted to the dedicated private sidecar IP and is not published on a QNAP host port.
- Execution model: no generic shell, source-code, module-import, callable, Docker-socket, privileged-container, or host-namespace execution path is introduced to MCP callers. QNAP deployment scripts execute only fixed operator-side Docker/shell operations.
- Persistence model: Phase 1 uses one writable MCP process against canonical SQLite. Future multi-container writers remain blocked until a single ledger-owner service exists or filesystem locking/concurrency is separately certified.
- Authentication model: tunnel runtime authentication uses the official OpenAI tunnel client and file-mounted runtime key. No custom bearer-token scheme is invented.
- Release model: the release bundle carries the exact Mesh build context, not a mutable external Mesh image dependency. Prepared image IDs are verified before and after deployment.

## Live acceptance still required

The 2026-08-25 read-only probe already established architecture, QTS/Docker/Compose versions, core/RAM headroom, qnet shape, private subnet non-overlap, filesystem type, and free-space evidence. The automated preflight/deploy/verify path now checks the deployment-time state it can observe, including current qnet ownership, canonical ledger, secret file, image IDs, resource controls, Compose rendering, health/readiness, non-tunnel denial, and backup integrity.

Items that remain genuinely product/operator-side are: creation/association of the OpenAI tunnel, tunnel permissions, runtime credential issuance, explicit canonical ledger source selection if needed, QNAP firewall/access-control policy outside Docker, total-NAS-loss backup/snapshot policy, and end-to-end ChatGPT Developer Mode connection/tool acceptance.
