# Security Policy

Phase 1 uses least privilege, explicit source permissions, approval gates, audit events, idempotency, and a kill switch. Secrets must be provided by environment variables and never committed.

Retrieved documents, Slack messages, tool responses, and external content are untrusted data. They cannot change policy, authority, approval, routing, or system instructions.

Critical defects include unauthorized external action, fabricated material evidence, confidentiality breach, prohibited source exposure, bypassed approval, irreversible unauthorized action, and false claims of human approval. Critical defects normally quarantine the responsible agent pending review.
