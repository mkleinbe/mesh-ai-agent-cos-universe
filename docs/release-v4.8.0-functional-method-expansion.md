# v4.8.0 Functional Method Expansion

Release date: September 12, 2026

Repository capability release: `v4.8.0`  
Canonical Phase 1 authority/runtime contract: `4.0.0`, unchanged  
Production QNAP deployment: `4.4.0`, unchanged

## Release intent

v4.8.0 strengthens the existing ten-agent Mesh organization with governed decision, commercial, finance, operations, knowledge, marketing, content, and communication methods adapted from reviewed donor sources. It does not create a competing operating system, new agent principal, new canonical state, or new autonomous authority.

## Material additions

- CoS deliberation classifier, independent multi-functional contributions, scenario composition, strategic work-graph alignment, and change readiness.
- AgentOps flow/cycle-time/bottleneck and assumption-gated capacity intelligence.
- Answer Desk answerability and source-health diagnostics.
- CRO pricing/packaging, commercial policy, deal review, forecasting, partnerships, channel economics, and RFP/RFI method depth.
- CFO commercial economics and corrected fixed-cost-to-serve deal discount math.
- COO process, capacity, vendor/partner dependency, resilience, and procurement-process diagnostics.
- Consultant Network Steward concentration, freshness, reliability, fallback, and contingency evidence.
- CMO growth/investment/change-readiness methods.
- VP Content inventory/proof/derivative lineage controls.
- Message Operations consumption of approved change/campaign execution metadata without approval expansion.

## Shared capability releases

- Mesh PPMD Bot advances separately to `v1.2.0` for reusable Base / Stress / Severe scenario stress testing.
- Mesh Messaging advances separately to `v1.3.0` for governed change communications.
- Revenue Intelligence, GTM Orchestrator, Mesh Data Analytics, and Mesh Devil's Advocate do not change in this release because their governing behavior remains sufficient.

## Explicitly rejected donor components

- donor company OS and orchestrators;
- donor file-based decision logger and `~/.claude/decisions/` memory architecture;
- donor company context as canonical Mesh state;
- `[INVOKE:role]` authorization/routing;
- static donor C-suite roster or added C-suite agents;
- raw deliberation/private chain-of-thought persistence;
- autonomous communications, deal approval, procurement, or staffing commitments;
- unsupported buyer intent/authority inference;
- donor thresholds or benchmarks promoted to Mesh policy.

## Compatibility

- exactly 10 registered agents;
- parentage unchanged;
- registry allowlists unchanged;
- direct Skill arrays unchanged;
- TaskLedger remains canonical operating state;
- Revenue Intelligence remains canonical commercial truth where designated;
- `COMPLETED != VERIFIED`;
- L4 remains qualified-human approval;
- L5 remains Michael-only;
- no runtime schema or QNAP image/container change;
- no new MCP connector, secret, OAuth, or network boundary.

## Rollback

The CoS Universe release is method/Skill/documentation plus a bounded deterministic calculator extension. If v4.8.0 introduces method drift, revert the v4.8.0 main commit and issue a corrective repository release. Do not roll back the healthy QNAP 4.4.0 deployment for a repository-capability defect because the runtime deployment is unchanged.

## Verification gate

Release is permitted only after the exact candidate passes full repository CI, v4.8 BDD/evaluation tests, quantitative boundary tests, FULL_REVIEW security verification, requirements gap audit, independent verification, and final main/tag/release alignment.
